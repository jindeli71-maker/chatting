# LINE Chat (Chatting) — User Manual

Live: [https://leekimteck.kolejsynergy.com/Chatting/](https://leekimteck.kolejsynergy.com/Chatting/)

## What it does

A LINE-style chat client. Pick a device layout, then sign in to send messages.

## How to use

1. Open the live URL.
2. Choose your device view (phone / desktop style).
3. Click **Continue to Login**.
4. Sign in with your chat account.
5. Open a conversation and send text or media.

## Tips

- Allow notifications if you want new-message alerts.
- Use a modern browser (Chrome, Edge, Firefox).
- If login fails, check caps lock and that the account was registered in this app, not a real LINE account.
